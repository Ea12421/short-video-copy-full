# short-video-copy-full

A Chinese short-video copywriting Skill for turning topics, events, opinions, reference materials, or drafts into natural spoken scripts and consistent derived deliverables.

The Skill selects one primary mode, preserves claim/source boundaries, translates technical evidence into plain language, and performs a targeted anti-template/anti-AI-expression pass.
